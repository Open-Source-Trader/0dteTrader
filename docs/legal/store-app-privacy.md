# App Store Privacy Summary

- Contact information: account email, used for authentication and account operation.
- Financial information: brokerage connection identifiers and trading activity, used for app functionality.
- Identifiers: user ID and APNs device token, used for authentication and notifications.
- Diagnostics: limited operational error logs, used for reliability and security.
- User content: optional prompts and selected market/account context only when an AI analysis feature is invoked.
- Tracking: none. Data is not sold or used for cross-company advertising tracking.
- Deletion: available from Profile > Delete Account.

The human-readable public policy endpoint is `/v1/legal/privacy-policy` on the deployed API origin; `/v1/legal/privacy` remains the application JSON endpoint.
