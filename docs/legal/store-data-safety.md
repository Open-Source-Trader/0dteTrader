# Google Play Data Safety Reference

0dteTrader does not currently ship an Android client. If one is published, declare account email, financial activity, device identifiers, and diagnostics as collected for app functionality, security, and optional notifications. Declare encryption in transit, account deletion support, and no sale or advertising use, subject to the actual hosting operator's practices.

If AI analysis is enabled, also declare user prompts and the selected market/account context sent for the request. The exact declaration must match the configured model provider and hosting operator; do not reuse this reference without validating the shipped build's actual data flows.
