# Store Review Notes

The app is an open-source brokerage client. It does not custody assets or provide investment advice. Reviewers can use practice mode with test credentials supplied through the review channel.

Required disclosures are available from Profile without starting a trade. Terms and risk acceptance are versioned server-side. The Privacy Policy is publicly reachable at `/v1/legal/privacy`. Account deletion is available in Profile and removes the user row plus all user-owned data through database cascade constraints.
